# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x   | Yes       |

## Reporting a vulnerability

Do **not** open a public issue for security vulnerabilities.

Report them via [GitHub Security Advisories](https://github.com/alirazaanis/vitalroute/security/advisories/new)
(private report) or contact the repository maintainer directly.

Include:

- Description of the vulnerability
- Steps to reproduce
- Impact assessment (if known)
- Suggested fix (optional)

Maintainers aim to acknowledge reports within 7 days.
